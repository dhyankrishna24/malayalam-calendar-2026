# 💎 Malayalam Calendar 2026 - Liquid Glass Edition (മലയാളം കലണ്ടർ)

A modern, ad-free, ultra-lightweight Malayalam Calendar Android application built with **Jetpack Compose**, **Material 3**, and a gorgeous **Liquid Glassmorphism UI**.

## ✨ Features
- **💎 Liquid Glass UI**:
  - Translucent frosted glass tiles with ambient background light refraction.
  - Floating liquid glass month navigation pill.
  - Radiant glowing selection and "Today" badge with amber/rose gold gradients.
  - Frosted liquid glass Bottom Sheet for date details.
- **Pure Calendar**: Only the calendar and Panchangam — no ads, no shopping, no horoscopes, zero bloatware.
- **Interactive Date Details**: Click on any date to pull up complete day details:
  - Malayalam Date & Month (കൊല്ലവർഷം, e.g. ധനു, മകരം 1201)
  - Nakshathram (നക്ഷത്രം)
  - Tithi (തിഥി)
  - Sunrise & Sunset (സൂര്യോദയം, സൂര്യാസ്തമയം)
  - Moonrise & Moonset (ചന്ദ്രോദയം, ചന്ദ്രാസ്തമയം)
  - Rahu Kalam, Yamaganda, Gulikai Kalam (രാഹുകാലം, യമഗണ്ഡം, ഗുളികകാലം)
  - Auspicious times (Abhijit, Brahma Muhurta, Amrit Kalam)
  - Festivals & Observances (വിശേഷദിവസങ്ങൾ / വ്രതങ്ങൾ)
- **Year Support**: 2026 and 2027.
- **Bilingual**: Instant toggle between Malayalam (`മല`) and English (`EN`).
- **Offline & Privacy-Focused**: Zero internet permissions requested.

## 🚀 Automated Cloud Builds (GitHub Actions)
This project is compiled exclusively in the cloud via **GitHub Actions**. Every push to `main` compiles the APK and attaches it to GitHub Releases and Artifacts.

## 📱 Compatibility
- Minimum SDK: Android 6.0 (API 23)
- Target SDK: Android 15 (API 35)
- Compatible with all Android devices including POCO F1 (MIUI / Android 9, 10).
